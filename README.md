# 🕌 المنارة (Al-Manara)

تطبيق تذكير ديني: أذان تلقائي حسب موقعك (محسوب فلكياً بدون نت)، تذكير "صلِّ على النبي ﷺ" كل ١٠ دقايق، مهمات يومية روحية، وفحص تحديثات.

⚠️ تطبيق شخصي (side-load)، مش من متجر Google Play.

---

## ⚠️ خطوة إلزامية أولى: ملفات الصوت

**التطبيق ما بيجي بملفات صوت جوّاه** — لازم تجيبها إنت من مصدر تثق فيه (لا أقدر أنشئ أو أوفر تسجيلات صوتية).

جيب ملفين **mp3** وحطهم بمجلد `app/src/main/res/raw/` بهالاسمين بالضبط:
- `adhan.mp3` — تسجيل الأذان الكامل
- `salawat.mp3` — تسجيل صوتي قصير يقول "اللهم صلِّ على محمد" أو مشابه

```bash
cd FightArena  # أو مكان مشروع AlManara عندك
cp /path/to/your/adhan.mp3 app/src/main/res/raw/adhan.mp3
cp /path/to/your/salawat.mp3 app/src/main/res/raw/salawat.mp3
rm app/src/main/res/raw/.gitkeep
```

**بدون هالملفين، البناء رح يفشل** (الكود بيشير إليهم مباشرة عبر `R.raw.adhan` و `R.raw.salawat`).

## ⚠️ خطوات Firebase (بس لفحص التحديثات — كل شي تاني بدون نت)

### 1) أنشئ مشروع Firebase جديد (أو استخدم مشروع "Famly" الموجود)
1. أضف تطبيق أندرويد جديد بالمشروع
2. **Android package name:** `com.ishhf.almanara`
3. نزّل `google-services.json` وحطه بمجلد `app/`

### 2) فعّل Anonymous Authentication
Firebase Console → Authentication → Get started → فعّل Anonymous

### 3) فعّل Firestore + الصق نفس الـ Rules المعتادة
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

### 4) (اختياري الآن) جهّز وثيقة فحص التحديث
بـ Firestore Console، اعمل مجموعة `app_version` ووثيقة `current` فيها:
```
versionCode: 2   (رقم، لازم أعلى من رقم النسخة الحالية بالتطبيق)
versionName: "1.1"
apkUrl: "https://github.com/<اسمك>/<repo>/releases/download/v1.1/app-debug.apk"
```
لما تبني نسخة أحدث لاحقاً، ارفع الـ APK كـ **GitHub Release** (مو بس Artifact)، وحدّث هالوثيقة بالرابط ورقم النسخة الجديد. أي شخص يفتح التطبيق وعنده نسخة أقدم رح يطلعله بانر "تحديث الآن".

## ✨ شرح الميزات

- **مواقيت الصلاة:** تحسب بمعادلة فلكية من موقعك (خط الطول والعرض) بدون أي اتصال إنترنت بعد أول تفعيل. **يُنصح تتأكد من دقتها بمقارنتها بمواقيت مسجد قريب منك أول مرة** — المعادلة تقريبية زاوية الفجر ١٨° والعشاء ١٧° (قد تختلف قليلاً حسب منطقتك).
- **الأذان:** منبّه محلي (AlarmManager) بيشتغل حتى لو التطبيق مقفول تماماً وبدون نت، بيشغّل ملف الأذان كامل.
- **صلِّ على النبي:** نفس الفكرة، كل ١٠ دقايق.
- **المهمات اليومية:** قائمة (أذكار صباح/مساء، تسبيح، استغفار...) تتصفّر كل يوم جديد، وتقدر تضيف مهامك الخاصة من نفس الشاشة.
- **فحص التحديث:** عند فتح التطبيق، يفحص Firestore — إذا في نسخة أحدث يطلع بانر "تحديث الآن"، وإذا لا ما يطلع شي.

## ⚠️ ملاحظات صادقة
- على بعض الهواتف (خصوصاً شاومي، هواوي، سامسونج بأوضاع توفير طاقة قوية)، قد يحتاج تفعيل "السماح بالعمل بالخلفية" يدوياً من إعدادات النظام عشان المنبهات تضل تشتغل بانتظام.
- المعادلة الفلكية تقريبية، مش بديل رسمي عن مصادر دينية معتمدة لمنطقتك لو كنت محتاج دقة عالية جداً.

## 📖 ميزة اختبار حفظ القرآن (اختيارية)

هاي الميزة محتاجة ملف نص قرآن **موثوق ومرخّص** — ما كتبنا أي آية من الذاكرة (خطر الخطأ بنص مقدّس).

### حمّل النص من مصدر موثوق:
1. روح لـ 🔗 https://tanzil.net/download
2. اختار **Simple Clean Text** (بدون تشكيل، أنسب للمقارنة الصوتية)
3. حمّل الملف (نص عادي، آية كل سطر بالصيغة `سورة|آية|نص`)

### حوّله لصيغة JSON بسيطة يفهمها التطبيق:
الملف لازم يكون بالشكل:
```json
{
  "surahs": [
    {
      "number": 1,
      "name": "الفاتحة",
      "ayahs": [
        {"number": 1, "text": "بسم الله الرحمن الرحيم"},
        {"number": 2, "text": "الحمد لله رب العالمين"}
      ]
    }
  ]
}
```
لو عندك خبرة بسيطة بالبرمجة ممكن تحوّل ملف Tanzil لهالصيغة بسكربت بسيط. أو إذا حابب، احكيلي وممكن أساعدك تكتب سكربت تحويل بلغة بايثون تشغّله بـ Termux.

احفظ الملف الناتج باسم **`quran_simple_clean.json`** بمجلد:
```
app/src/main/assets/quran_simple_clean.json
```

**النص من Tanzil.net مرخّص Creative Commons BY 3.0 — لازم تذكر المصدر بأي مكان بالتطبيق أو التوثيق (موجود هون بالـ README، كافي).**

⚠️ **بدون هالملف، شاشة اختبار الحفظ بتفتح وبتعرض رسالة توضح إنه الملف مش موجود بعد — باقي التطبيق يشتغل عادي بدونها.**
